# Phase 2-B-1 — C10 숙박업 생산지수 독립 교차검증

검증일 **2026-11-23 KST**. PR #66 병합 후 main `dbfbf8aeb06767e61226c1f39dda9a7d86598f9c` 기준이다. [Phase2-A](../model-indicator-source-audit/README.md)의 C10을 조사했다. 코드·모델·운영 수집·공개 발행을 변경하지 않는 문서 전용 결과다.

**결론: 독립 원표 수준값 교차검증은 미완료이며, 본격 상관관계·모델 기여도 분석은 보류한다.** 기존 ECOS 원본69개월은 재확인했다. 새로 확보한 공식 재공표 파일에서 동일 월 수준값3개를 실제 대조했으나 모두 값이 달랐다. 서로 다른 수집/공표 시점이므로 이를 ECOS 오류나 공식 정정으로 단정하지 않는다.

## 1. 고정한 대상과 증거 수준

- ECOS `901Y038 / I51ADA / 2`, `market_lodging`, 월간 **2020=100 불변 원계열·비계절조정**, 숙박업 단독.
- 보유 기준자료: **2021-01~2026-09, 69개월**. 원값은 Decimal 문자열로 취급하며 새 인증 조회를 하지 않는다.
- 숙박·음식점 합계, 호텔업만의 지수, 명목/경상지수, 계절조정지수, 분기/연간 평균을 동일 계열로 대체하지 않는다. 단위가 같다는 사실만으로 모집단·지수 유형의 동일성을 인정하지 않는다.
- **직접 원표 대조**: 원작성기관의 동일 업종·종류·기준년 월별 수준값과 대조하는 것.
- **공식 재공표 대조**: 다른 공식 기관이 KOSIS 수치를 인용한 별도 공표물과 대조하는 것. 같은 원천일 수 있으며 독립적인 데이터 생성 검증이 아니다.
- **변화율 보조 대조**: 원작성기관 PDF의 반올림된 원계열 YoY와 비교하는 것. 수준값 대조를 대신하지 못한다. 계절조정 전월비는 이 비교에서 제외했다.

## 2. 이번에 실제 재확인한 기존 ECOS 원본

기존 `tools.validate_market_weather_foundation.load_evidence`와 기준 패키지 생성기만 오프라인으로 사용했다. 수집 엔진·Client·승인 주입은 실행하지 않았다.

- 기존 공식 응답63개의 SHA-256을 수집 metadata 및 manifest와 대조하고 원본 페이지와 집계 JSON이 같은지 확인했다. 이는 전체9계열 원본 묶음의 검사이며 숙박업의 원본 페이지는7개다.
- 재생성한 **628개 월별 fingerprint**가 기존 `fixtures/macro_market_step3_baseline.json`과 일치한다. 그중 C10의69개월에 대해 표·항목·단위·월 집합을 확인했다. fingerprint만 보고 원본을 읽었다고 주장하지 않았다.
- C10 집계 원본 SHA-256: `5aab7182e8356d59f5bdfb6671489fabc8dfc40a5e37b3c174f2527d34a2b6d9`.
- Phase2-A에서 확인한69개월의 결측·중복·음수·0값0/39개월 연속 충족을 이번 원본·월 집합 재확인과 연결한다. 이는 ECOS 내부 일관성 검사이며 독립 원표 대조가 아니다.
- 기존 최신3개월 인증 성공 기록을 전체69개월의 새 인증 조회로 확대하지 않는다. **이번 신규 인증 요청0회**다.

## 4. 원작성기관 공식 공표자료 — 변화율 보조 대조

[국가데이터처 2026년9월 산업활동동향](https://mods.go.kr/board.es?act=view&bid=216&list_no=447747&mid=a10301050100)의 [공식 PDF](https://mods.go.kr/boardDownload.es?bid=216&list_no=447747&seq=1)를 웹 조회 도구로 읽었다. **보도시점 2026-10-30 08:00 KST**, PDF page index29/인쇄26쪽의 숙박업 단독 행을 사용했다.

실행 환경에서 원본 PDF 다운로드는503이었다. 같은 공식 문서의 HWPX와 [정부 정책브리핑 재게시 PDF](https://www.korea.kr/archive/expDocView.do?docId=41931&group=S)도 검토했으나 다운로드503이었다. 같은 요청을 반복하지 않았다. 웹 도구의 공식 PDF 추출 성공과 **로컬 PDF 원본 바이트 확보 성공은 구분**한다. PDF 원본 SHA-256을 생성했다고 주장하지 않는다.

- 숙박업 **원계열 전년동월비**4개: **2025-09, 2026-07, 2026-08, 2026-09**.
- 기존 ECOS 수준값에서 Decimal로 YoY를 계산하고 공식 표의 소수1자리와 비교했다. **3개 일치(2026-07~09), 1개 차이(2025-09)**다. 정확한 미반올림 변화율의 일치가 아니라 **0.1%p 표시 정밀도**에서의 비교다.
- PDF 본문의 전월비는 계절조정 기준이므로 비계절조정 ECOS MoM와 비교하지 않았다. 분기 증감률·숙박음식 합계·호텔 하위지표도 대조에 넣지 않았다.
- 부록의 수준값 표는 상위 업종 등이며 이번 확인에서 숙박업 단독 월별 수준값69개를 추출하지 못했다. 위4개 변화율 대조를 수준값4개월/8개월 검증으로 바꾸지 않는다.

## 7. 통계 정의·정정·공표 시점 위험

- 원작성기관 PDF의 설명상 불변지수는 경상지수에서 가격 변동을 제거한 지수이고 계절조정은 별도다. 객실 가동률·매출 총액·관광 목적 이용만의 실적이 아니다. 비관광 숙박도 포함할 수 있으며 관광 비중을 계산할 분해 자료는 없다.
- 2023년 기준년/산업분류 개편 이력은 존재하지만 같은2020 기준 표시 안에서도 소급 수정이 가능하다. 이번3개 수준값 차이를 특정 개편 탓으로 확정하지 않는다. 앞으로 새 기준년·정의가 나오면 별도 계약/빈티지로 분리하고 자동 연결하지 않는다.
- 원작성기관 공표문은 최근2~3개월에 잠정치가 포함될 수 있다고 고지한다. 이 문구만으로 ECOS69개 관측의 finality를 일괄 provisional/final로 변경하지 않는다. ECOS 개별 공표일은 미확인/null, 원본 수집일은2026-11-12다.
- 이번9월 원작성 공표는10월30일이다. 조회/수집 시각·문서 작성일·웹 게시시각·실제 통계 공표시각을 구분한다. 69개월 전체의 과거 공표일·당시 빈티지는 미확보다.
- 계절성이 큰 원계열, 코로나19 이후 회복/기저효과, 수정 시차 때문에 단순 상관을 관광시장 설명력으로 해석할 수 없다. 이번 상관계수·기여도·새 가중치·점수는 계산하지 않았다.

권리의 충족 범위와 다음 조치는 [권리·시점 표 및 Phase2-B-2 조건](rights-and-next-steps.md)에 구분한다. 이 결과는 운영·모델 채택·게시 승인이 아니다.

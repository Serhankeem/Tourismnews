# Model Signal — 지표 등록 및 설명변수 확장 계획

2026-11-23. PR #65의 확장 설계이며 **수집·게시 승인 또는 신규 변수 활성화가 아니다**. Model Signal v1.0.0은 방한객과 명목 일반여행수입만 사용한다. 아래 18개는 두 활성 지표를 제외한 **향후 조사 후보**다. 후보 모두를 합산한다는 제안도 아니다. 표·항목코드, 실제 원본, 권리와 비교 가능성이 입증되지 않은 것은 미확보/미검증으로 남긴다.

## 등록부와 판본의 계약

`site/market-signal-registry.js`가 지표 ID·계약 revision·분석 영역·표시명·공식 정의·단위·제공기관·수집 검증 방법·공식 URL 규칙·권리/파일 해시·승인기간을 선언한다. 여섯 영역은 `demand / consumption / supply / industry / macro / sentiment`다. 영역은 분류 메타데이터이며 영역별 점수나 가중치를 자동 생성하지 않는다.

별도 모델 manifest가 **활성 ID + 계약 revision + 정확한 유리수 가중치**를 선택한다. 등록부에 항목 또는 새 계약 revision을 추가해도 기존 manifest는 바뀌지 않는다. `defineVersion()`은 manifest에 지정된 계약만 복사해 깊게 동결한다. 모델의 `createModel()`도 분리된 복사본을 동결하며, ID 중복·계약 누락·알 수 없는 검증 규칙·비정상 가중치·합계 1 불일치·지원하지 않는 계산식을 사전에 거부한다. 런타임 `evaluate()` 옵션으로 가중치·공식을 바꾸지 못한다. 원자료가 부족한 축을 빼고 남은 가중치를 재정규화하지 않는다.

v1.0.0의 활성 지표는 `kto_inbound@1`과 `kto_tourism_receipts@1`, 각각 `1/2`다. 원값 계약·가중치·YoY/3개월 평활/24개월 중간순위·날씨 구간·시차 한도를 판본에 고정한다. 전체 계약의 정렬된 JSON SHA-256은 `47602b7f2f459ca14e9a35e6053ecd5b129a0a51047c940d3c284c544dfebc84`이며 회귀 테스트에서 확인한다. 계약 수정은 기존 revision을 편집하지 않고 새 revision으로 등록한다. 지표/가중치/공식 변경은 새 모델 버전으로만 검토한다. 기존 판본은 해당 계약과 알고리즘을 계속 보존한다.

계산 핵심은 `Σ(weight_i × percentile_i)`를 BigInt 유리수로 처리한다. 계열 식별·동일 최신월 확인·검증·기여도·미래 월 제외 검사는 N개 계열에 공통 적용한다. `IDS`, `CONTRACT`, `METHOD`는 기존 호출자 호환용으로 동결 판본에서 파생한 읽기 전용 별칭이며 계산의 두 계열 하드코딩이 아니다. UI 명칭과 가중치도 같은 판본에서 읽는다. `createModel()`은 코드에서 명시적으로 구성하는 연구/개발 API이며 URL·환경변수·외부 JSON으로 운영 판본을 선택하거나 활성화하는 통로가 아니다.

현재 알고리즘 `smoothed_yoy_midrank_v1`은 월별 비음수 안전 정수 원값, 양수 YoY 분모, 3개월 평활과 직전 24개월 참조를 지원한다. 다른 지표를 같은 방식으로 등록하는 데 계산 핵심 수정은 필요 없다. 다만 지수·환율 소수점, 연간 자료, 심리지수·금리의 수준/차분처럼 **다른 수치 계약과 변환**은 별도 검증된 알고리즘 판본이 필요하다. 이를 임의로 정수 반올림하거나 기존 성장률 모델에 끼워 넣지 않는다. 일반화된 계산 가능성은 통계적 적합성이나 권리 승인과 별개다.

## 확보와 통계 검증의 단계

1. **원본/권리**: 공식 XLSX/CSV/API 원본, SHA-256, 기준월·조회시각·실제 공표시각·제공기관·잠정/확정·수집/내부 분석/공개 조건을 분리 기록한다. 공식 로그인·승인·다운로드 절차를 따른다. 원본이 없으면 확보 0건, 대리지표로 대체하지 않는다. 기존 독립 원표 미재파싱·역사적 as-of 미확인 한계를 유지한다.
2. **계약/시계열**: 단위·배율·기준년·분류·모집단·기간·공표 주기·정정·빈티지를 고정하고 중복·누락·0 분모·이상치·음수·정의 단절을 검사한다. 월 자료를 확보해도 현재 알고리즘에 필요한 39개월 연속 원값을 별도 확인한다. 연간/분기 자료를 보간하거나 오래된 값을 최신 월로 이월하지 않는다.
3. **역할/변환**: 관광 직접 수요와 대리/가격/환경/심리를 구분한다. CPI·환율·금리·심리의 방향과 수준/차분은 분석 목적에 따라 사전 명시한다. 모든 변수를 YoY·양의 성장·균등가중으로 자동 통합하지 않는다. 영역 내 유사 통계와 국적별 부분집합은 독립 신호로 중복 계산하지 않는다.
4. **중복/추가 설명력**: 동일 기준월/가용시점으로 정렬해 원값·변환값의 상관, Spearman 순위상관, 공선성 및 중첩 모집단을 분석한다. 두 활성 축만의 기준 모델과 새 축을 추가/제거한 모델의 순위·날씨 변동·정정 민감도를 비교한다. 공통 추세로 발생한 상관을 인과·예측력으로 해석하지 않는다. 변수 수 증가 자체를 개선으로 평가하지 않는다.
5. **검증 설계 고정**: 결과를 보기 전에 개발/검증 시점 분할, 참조기간·변환·가중치 후보·날씨 표시 구간·비교 목적·허용 변동 기준을 새 버전 문서에 사전 등록한다. 코로나19 회복기 포함/제외, 24개월 외 참조창, 자료 정정, 가중치 민감도를 연구로 비교한다. 최종 관측 결과를 보고 구간이나 가중치를 바꾸지 않는다. 영역마다 변수 수가 다르면 단순 N개 균등가중이 영역 중요도를 왜곡할 수 있으므로 영역별 중복과 가중 설계를 별도 심사한다.
6. **시점/재현**: 평가월 이후 원값을 제거하는 walk-forward 불변식을 모든 축에 적용한다. 공표 시차를 반영한 입력 마감과 빈티지 스냅샷을 앞으로 축적한다. 현재 수정 빈티지만 있는 과거는 `retrospective_current_vintage`, 실제 당시 공개 빈티지 증거가 있을 때만 `as_of_verified`로 구분한다. 심리 전망의 조사 대상기간과 실제 관측기간도 혼동하지 않는다.
7. **승격**: 수집 권리·공개 권리·통계 계약·교차검증·충분한 이력·누출 방지·새 버전 검토가 완료된 지표만 명시적 manifest로 제안한다. Codex는 조사·격리 검증·새 판본 테스트를 수행할 수 있지만 이용허락 문의/운영 활성화/공개 승인은 운영자가 별도로 결정한다. 검증 실패·시차 초과·필수 축 결측이면 판정 유보하며 기존 공개 원장을 보존한다.

## 현재 변경의 검증 범위

합성 3계열(`1/2, 1/3, 1/6`)과 4계열(`1/4`씩)을 등록부/판본만으로 구성해 같은 계산 핵심에서 실행한다. 합성 ID·값은 테스트 코드 안에만 있으며 운영 등록부·운영 데이터·공개 JSON에 추가하지 않는다. 세 번째 계열 결측·미연동·월 불일치·권리/단위 불일치·중복도 모두 유보한다. 판본 동결·원본 객체 변경·등록부 확장·새 계약 revision·잘못된 가중치·공식 변경 거부를 회귀 검증한다.

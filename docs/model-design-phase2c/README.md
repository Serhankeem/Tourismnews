## 3. Model A/B/C 비교

| 구조 | 산식·설계 | 이번에 실제 계산한 것 | 판단 |
|---|---|---|---|
| A: 기준 2변수 | 월 YoY → 3개월 평균 → 직전 24개월 중간순위 → 50:50. 기존 구간·계약 보존 | 31개월 점수 및 기존 표시 구간. 최신 2026-09 **62.50/구름 조금** | 방한·명목 수입의 상대 성장 신호로 유지. 전체 시장 지수는 아님 |
| B: 영역별 복합 | 수요·소비·산업활동을 우선 분리. 영역 안 중복 선별 후 구성비를 고정하고 영역 간 가중은 별도 판본 심사 | 수요·소비 영역별 순위만 계산. 산업활동·국내관광은 빈 상태, 31개월 모두 전체 지수 유보 | 영역별 변수 개수가 많다고 중요도가 커지지 않게 설계. 빈 산업 축을 빼고 가중 재정규화하지 않음 |
| C: 핵심 + 환경 | 활동 핵심은 A 그대로. 환율·가격·심리는 별도 단위/방향/시차의 설명 블록 | 핵심 결과는 31개월 모두 A와 정확히 같음. 정량 적격 환경계열 0개이므로 환경 블록은 비움 | 다음 정보구조로 권장. 현재 수치 개선을 입증한 새 모델이라는 뜻은 아님 |

B의 연구용 영역 함수는 같은 영역 내 상대 위치의 평균을 별도로 보여 주며, 다른 영역으로 자동 합산하지 않는다. 동일 합성 변수를 영역에 복제해도 해당 영역 점수가 증가하지 않는지 테스트했다. 이는 데이터가 채워진 최종 B의 가중치 확정이 아니다. 산업 지표를 확보해도 국내관광 공백이 남으면 “한국 관광산업 전체”라는 이름을 쓰지 않는다.

C의 장점은 부호가 불명확한 환율·가격을 활동 점수로 오인하지 않으면서 맥락을 제공하는 것이다. 단점은 환경과 활동의 관계를 편집자가 신중히 해석해야 하고, 단일 종합 숫자로 축약되지 않는다는 점이다. 직접 합산은 간단하지만 임의 부호·중복·환산 효과를 경기 신호로 만들 위험이 커서 권하지 않는다. 방한·국내·해외 시장은 먼저 별도 하위 모니터로 설계하고 자료·정의를 확보한 후 통합 필요성을 심사한다.

## 4. 실험 고정과 실제 통계 결과

[protocol.json](protocol.json)을 **새 비교 계산 전에 동결**했다. SHA-256 `bf46a92240a9bfbd165a583d80c20266bc951eb3c6c960e01652d5d35e38cfcb`. 기존 v1.0 결과는 이미 알려져 있었으므로 맹검·독립 사전등록이라고 주장하지 않는다. 새로운 결과를 보고 창 길이·가중치·날씨 구간을 재조정하지 않았다.

원값·YoY·3개월 평활 YoY를 구분한다. 비계절조정이며 보간·이월·0 대체·이상치 삭제·윈저화 없음. 분모 0은 계산 불가, 결측은 공통 유효 월만 사용한다. 회고 평가는 각 월 이후 원값을 제거하며 월별 입력은 미래 월을 참조하지 않는다. **현재 수정 빈티지**의 회고 연구이고 역사적 실시간 백테스트가 아니다. `as_of=t+1`은 월 필터용 연구 가정일 뿐, 당시 자료가 실제 공개되어 있었다는 증거가 아니다.

전체 기간 방한 YoY의 최대는 727.31%, 3개월 평활 YoY의 최대는 571.67%였다. 이 극단값을 삭제해 결과를 개선하지 않았다. 작은 분모와 회복 과정이 들어간 과거 분포를 현재의 정상적인 경기 기준으로 자동 해석할 수 없다는 이유로, 아래 원값 사용 제한을 별도 비교했다.

### 두 핵심 계열의 상관·중복

Pearson은 공통 수준/변화의 선형 관계, Spearman은 동률 중간순위를 쓴 순위 관계다. 원래 단위가 다른 수준 상관도 계산 가능하지만 공통 추세를 제거하지 않으므로 해석을 제한한다.

| 원값 사용 제한 | 변환·실제 공통 기간 | n | Pearson | Spearman |
|---|---|---:|---:|---:|
| 없음 | 수준 2021-01~2026-09 | 69 | 0.9181 | 0.9440 |
| 없음 | YoY 2022-01~2026-09 | 57 | 0.2615 | 0.0614 |
| 없음 | 평활 YoY 2022-03~2026-09 | 55 | 0.3457 | 0.1767 |
| 2022-12 이하 원값 제외 | 수준 2023-01~2026-09 | 45 | 0.9000 | 0.8988 |
| 동일 | YoY 2024-01~2026-09 | 33 | -0.0796 | -0.1437 |
| 동일 | 평활 YoY 2024-03~2026-09 | 31 | -0.2932 | -0.0629 |
| 2023-12 이하 원값 제외 | 수준 2024-01~2026-09 | 33 | 0.8923 | 0.8793 |
| 동일 | YoY 2025-01~2026-09 | 21 | 0.2820 | 0.1182 |
| 동일 | 평활 YoY 2025-03~2026-09 | 19 | 0.7259 | 0.7474 |

수준 상관만으로 두 계열이 불필요한 중복이라고 판정할 수 없다. 변환·기간에 따른 차이가 크며, 수입과 방한 규모의 모집단·가격·회복 과정도 다르다. 특히 마지막 19개 평활 관측의 높은 상관을 개선 근거로 선택하지 않는다. 중첩 3개월 평균과 시계열 자기상관 때문에 n을 독립 표본 수로 볼 수 없다. p값·통계적 유의성·인과·예측 정확도는 주장하지 않는다. A/B/C는 회귀 모형을 적합하지 않으므로 **VIF는 적용하지 않았다**.

- 위 7개월의 월간 절대 변화 평균은 4.5139점(6건)이지만 전체 31개월과 시기·표본이 다르다. 공통 7개월 점수는 기존 A와 같으므로 **팬데믹 제거로 모델이 안정화됐다는 비교가 아니다**. 회복기 전체를 제거한 장기 안정성을 검증할 관측 길이가 부족하다.
- 미래 월을 잘라낸 prefix 비교 및 미래 월 값을 오염시키는 검사 위반 **0건**. 별도 Fraction oracle **217개 대조 통과**. 같은 입력·코드로 반복한 결과 파일 3개의 바이트가 일치했다.
- 최신월에서 두 축 각각 ±1 저장 단위·±1%의 **가상 복사본 정정 스트레스** 8건과 결측 2건을 검사했다. ±1 단위는 62.50 유지, ±1% 범위는 60.4167~64.5833으로 같은 구간, 결측은 둘 다 판정 유보였다. 모두 반복 재계산이 동일했다. 실제 공식 정정 사건의 재현이나 모든 정정 규모에 대한 안정성 보증은 아니다.

정확한 집계는 [results.json](results.json)에 있다. 월별 점수·변형 입력·가공 시계열은 공개하지 않았다. **관광산업 전체의 외부 정답 지표가 없으므로 어느 모델의 경기 설명력 또는 예측 정확도가 더 높다고 입증하지 못했다.**

## 5. 최종 연구 판정과 최소 다음 작업

1. **전체 관광시장 지수는 현재 타당하지 않다.** 방한·국제수지 수입 편중, 국내 수요/소비·산업활동·공급 공백을 명시해야 한다.
2. **현재 핵심은 기존 두 계열이다.** 18개 중 새로 최종 투입 적격이 확인된 변수는 0개다. 검증되지 않은 지표로 4~6개를 맞추지 않는다.
3. **환율·CPI·금리·심리는 별도 맥락이 적절하다.** 각 원본·정의·권리 검증이 끝난 범위만 보여 주고 관광활동과 같은 방향으로 합산하지 않는다. 현재 추가 환경 수치를 계산한 것은 아니다.
4. **실질적인 수치 개선은 입증되지 않았다.** C의 핵심이 A와 동일한 것은 설계상 동일성이고 성능 향상이 아니다. B의 영역 공백을 보이는 것과 C의 해석 분리가 다음 개발의 가치다.
5. **다음 비공개 프로토타입은 C형 정보구조로 가능**하다. A 계산을 유지하고 두 축·기준월·지연·유보와 빈 환경 상태를 분리한다. 새로운 4변수 점수 구현은 아직 보류한다.

확장에 필요한 최소 데이터는 **검증된 월별 산업활동 1개**와 **국내관광 수요 또는 소비 1개**다. 전자는 C10 원표 차이 해소 또는 C12의 정확한 산업별 원본, 후자는 C02의 월별 공식 공표 가능성 또는 C05의 공식 전국 소비 원본을 우선한다. 모두 공통 기간·출처·권리·정정·공표 시점을 확인해야 한다. 현재 산식을 재사용하려면 공통 연속 39개월이 최소이며 이것만으로 안정성을 보장하지 않는다. 여러 채널이 충분해져도 전체 관광산업 대표성은 별도 심사한다.

사용자 조치는 원표 차이 해소에 필요한 공식 자료 제공/문의 결정, 국내 월별 자료의 정상 다운로드·이용 범위 확인, 다음 **비공개 연구 범위** 결정이다. 기존에 허용된 연구를 새 승인 체계로 바꾸지 않는다. 기관 문의·인증 API·운영 활성화·게시 승인은 이 연구로 자동 발급하지 않는다.

## 구현과 권한 경계

`src/macro/weather_publication.py`는 **승인 발급기나 배포 도구가 아닙니다.** 별도 편집/게시 기록과 운영자가 사전에 신뢰한 기록 해시를 검증합니다. 디스크에 공개 파일을 쓰는 API·CLI·스케줄은 없습니다.

1. 운영자가 따로 관리하는 `Trust`의 editorial/publication 핀 집합을 분리합니다. 각 핀은 기록 원시 SHA-256, 승인자 GitHub 식별자, 승인시각, 철회 여부입니다. 기록 안의 approved/이름/날짜를 자체 신뢰하지 않습니다. 편집 기록을 게시 기록으로 재사용할 수 없습니다. 같은 사람이 맡더라도 별도 결정·기록·역할 핀이 필요합니다.
2. 편집 원고의 정확한 UTF-8 바이트 해시, 대상월·편집 revision·승인시각·입력 스냅샷/원본 manifest·방법론·마감과 분석 시각을 연결합니다. 핀을 검증하기 전에는 기록에 들어 있는 파일 경로를 따라가지 않습니다.
3. 현재 설정/정책으로 통계 적격성·원값·단위·MoM/YoY·비교월·원본 빈티지를 기존 엔진으로 재검증합니다. 원래 snapshot 승인만으로 현재 철회/만료를 우회하지 않습니다. 입력은 복사해 검증/투영 사이 외부 변경을 방지합니다.
4. 별도 게시 기록은 원고 해시·기준월·편집 revision·편집 기록 해시·입력 원장 해시, 공개 계약 및 투영 구현 파일 해시, 공개 판본, 범위·기한·발행 기준시각에 연결합니다. 편집 이후 게시 결정이어야 하며 미래/만료/철회·다른 월/판본·범용 범위를 거절합니다.
5. **두 승인을 모두 통과한 뒤에만** 허용 필드로 공개 객체를 만들고 직렬화합니다. `audit()`의 결과를 permit로 재사용하지 않고 `public_json()` 호출마다 다시 검사합니다. 실제 r2는 게시 기록이 없어 객체 생성/직렬화 전에 `publication_approval_missing`으로 중단합니다.

### 신뢰 핀이 의미하는 것

`trust_file()`은 저장소 밖 운영자 관리 읽기 전용 파일만 읽으며 public payload·승인 기록 자체에서 핀을 만들지 않습니다. 기본 신뢰는 빈 집합입니다. 실제 격리 검증에는 이미 사용자가 승인한 **편집 기록 핀만** 넣었고 게시 핀은 비어 있습니다. 게시 승인 기록이나 게시 핀을 자동 생성하지 않았습니다.

이는 보호된 런타임이 주입하는 승인 기록 무결성 검증입니다. **외부 GitHub 신원 인증·전자서명 서비스는 구현하지 않았습니다.** 승인자·시각은 사용자 제공 기록과 독립 핀을 대조합니다. 운영자는 이 파일/인자를 관리하는 신뢰 주체이며 동일 OS 계정/관리자가 코드·핀을 고치는 공격을 방어하는 장치가 아닙니다. 0400은 변조 불가능 저장소가 아닙니다. 실제 통합 전에는 운영 신뢰 파일의 소유/관리·인증 경로·철회 책임을 지정하고, 웹 입력이나 공개 JSON이 해당 정책을 지정할 수 없도록 해야 합니다. 테스트용 합성 핀을 운영에 복사하면 안 됩니다.

호출자는 각 작업 및 업로드 직전에 신뢰 파일과 현재 통계 설정/정책을 새로 읽어 주입해야 합니다. 라이브러리가 파일 변경을 백그라운드 감시하거나 이미 주입된 객체를 자동 갱신하지는 않습니다. 오래 캐시한 Trust/설정 객체나 예전 audit 결과로 철회 확인을 대신하면 안 됩니다.

## 기존 이용조건과 통계 승인 재검증

TOURGO 기관 회신 요지는 기존 [이용조건 근거](../tourgo-macro-integration-v1/README.md)에 있습니다. 2026-11-09 확인된 비상업적 목적·출처표시 조건의 수치 외부 게시/가공 가능 근거를 유지합니다. 새 허가를 받았다거나 기존 근거가 미확인으로 되돌아갔다고 기록하지 않습니다. 이번에는 기관 회신을 새로 취득하지 않았습니다.

- 현재 운영 정책은 noncommercial / ads_enabled=false / paid_access=false입니다.
- 현재 TOURGO 조건은 noncommercial/free_access/no_ads/attribution 모두 true입니다. 월간 공개 게이트에서도 이를 확인합니다.
- 수집 승인: 2026-11-10~2027-02-08, 대상 기간 **2021-01~2026-09**.
- 원통계 게시 승인: 2026-11-11~2027-02-08, 대상 기간 **2021-01~2026-09**.
- 게이트는 이 기간 밖의 자동 확장도 거절합니다. 기존 수집/게시 승인을 새 월간 원고의 게시 승인으로 재사용하지 않습니다.
- KTO는 기존 공식 파일/정의/단위·KOGL-0 기록을 기존 엔진으로 검증합니다.

실제 원고 값·비교값/비교율·원문 URL·입력 빈티지는 기록과 일치합니다. 독립 XLSX 재파싱과 역사적 as-of 검증 미수행, 확정성·일부 원공표일 미확인, 산업 활동 부재와 종합 판정 보류는 유지합니다. 새 지표나 승인 범위를 활성화하지 않았습니다.

## 실제 원고와 공개 계약의 호환성

Step 15 v0.1 계약은 요약/근거 중심이어서 r2의 전체 해석 문단을 담을 전용 구조가 없었습니다. `schemas/market_weather_public_v2.schema.json`에 subtitle와 **원문 다섯 섹션**을 보존하는 article 구조를 추가했습니다. 제목·요약·두 근거·모집단/해석 범위·유의사항·출처를 임의로 재작성하거나 누락하지 않습니다. 지원하지 않는 구조/HTML은 조용히 잘라내지 않고 거절합니다. 공개 UI는 후속 구현에서도 허용 Markdown만 안전한 DOM으로 렌더링해야 합니다.

편집 revision `r2`와 공개 판본 번호를 구분합니다. 아직 공개한 적이 없는 첫 판본은 public revision 1이고 correction=null입니다. 현재 게이트는 첫 판본만 허용하며 정정 발행 프로토콜은 별도 후속 작업입니다. 원본 해시·승인 기록·내부 경로·검토자 개인정보·전체 진단·보조 계열을 공개 구조에 넣지 않습니다. 원고 상단의 검토 상태/기준월 메타데이터는 공개 본문에서 제외하고 계약의 기준월/발행 메타데이터로 구분합니다. 이 변환 방식도 게시 심사 대상입니다.

`issued_at`은 게시 기록이 지정한 발행 기준시각이며 실제 홈페이지 노출/배포 완료를 증명하지 않습니다. 데이터 원공표일로 대신하지 않습니다. 승인/기준시각과 실제 배포 확인은 구분해야 합니다.

실제 r2는 **구조/수치 호환성만 비공개로 검사**했습니다. 게시 승인이 없으므로 실제 공개 계약 객체나 공개 JSON을 생성하지 않았습니다. 양성 투영/Schema 검증은 명시된 합성 원고·숫자·승인을 메모리에서만 사용했습니다. Schema 형식 검증은 신뢰/의미 검증의 대체물이 아닙니다.

## 읽기 전용 검수 도구와 로컬 UI

```sh
python -m tools.market_weather_publication_audit \
  --editorial-record /absolute/private/editorial-approval-record.json \
  --trust-policy /absolute/operator-managed/readonly-trust.json
```

이 CLI는 고정 이유 코드·안전한 불리언만 출력하고 실제 원고·수치·기록 전문·키를 로그에 남기지 않습니다. 게시 승인 없음은 정상적인 차단이며 exit 1입니다. 승인 기록이 검증될 때만 exit 0을 반환하지만 출력은 계속 감사 결과이고 공개 콘텐츠가 아닙니다. `--output`/`--publish`/승인 발급 옵션은 없습니다.

```sh
python -m tools.market_weather_preview \
  --bundle /absolute/private/step13-bundle \
  --editorial-record /absolute/private/editorial-approval-record.json \
  --trust-policy /absolute/operator-managed/readonly-trust.json \
  --port 8050
```

기존 127.0.0.1 세션/Host/Origin/no-store/CSP 격리를 유지하며 r2 전체를 비공개로 렌더링합니다. 편집 승인 완료·게시 승인 없음·공개 JSON 생성 차단을 별도로 표시합니다. 원고/원장/승인 기록 파일 자체는 HTTP 정적 경로로 제공하지 않습니다. `/api/preview`는 보호된 비공개 API이며 공개 계약 JSON이 아닙니다. `/api/public`은 없습니다. 공개 렌더 모드는 플래그만 변경해도 계속 닫힙니다. 이 서버를 외부 호스팅/터널로 노출하면 안 됩니다.

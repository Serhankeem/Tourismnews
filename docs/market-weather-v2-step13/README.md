# Step 13 — 실측 진단 검증 및 비공개 그림자 발행

PR #54가 병합된 main `dc36b4f02b25f954e85bcdafb6262c2aed86b35d`에서 작업했습니다. [Step 12](../market-weather-v2-step12/README.md)의 두 핵심 지표만 사용합니다. 신규 ECOS·항공·카드·공급좌석은 제외하며 수집·게시 승인과 기간을 변경하지 않습니다.

## 구현과 검증 범위

`weather_diagnostic.py` v0.1.1은 증감 방향을 반올림된 문자열 대신 정확한 정수 원값으로 판단합니다. 표시상 +0.000000/-0.000000이 되어도 원값의 방향을 잃지 않으며, 비교 기준월의 정정도 별도로 경고합니다. 기존 Decimal 비교 계산과 원장 로직은 유지합니다.

`weather_shadow.py`는 수동 실행 전용 순수 분석·보존 도구입니다. 네트워크·수집·스케줄·게시 기능이 없습니다.

- 현재 빈티지 회고: 2021-01~2026-09의 69개월, 두 핵심 138개 관측. 정수 차이/분모의 별도 Decimal 산식으로 MoM 136개와 YoY 114개(총 250개)를 검산합니다. 2021년 12개월은 2020년 자료가 없어 두 핵심의 YoY 24개가 null이며, 2021-01의 MoM 2개도 null입니다. 보충하거나 0으로 해석하지 않습니다.
- 민감도: 전년 원값이 있는 2022-01~2026-09의 57개월 각각에 7가지 반사실 시나리오(총 399개)를 적용합니다. 미세한 증가/감소 반올림, 전년값 결측, 0 분모, 작은 분모의 극단적 기저, 비교 기준값 정정, 대상월 결측입니다. 모든 변경은 격리된 입력 사본에서만 합니다.
- 반사실 시나리오는 `counterfactual_copy`로 명시합니다. 변경된 값은 실제 공식 관측·실제 통계 정정이 아닙니다. 공식 원본 해시와 수정값이 일치한다고 주장하지 않습니다.
- 팬데믹 기저를 지우거나 정상 경기로 간주하지 않습니다. 원계열 MoM은 계절조정하지 않았고, 관측 방향을 호황·침체로 바꾸지 않습니다.
- 과거 당시 발표 빈티지를 확보하지 못했으므로 전 기간 `retrospective_current_vintage`, `historic_as_of_verified=false`입니다. 실시간 백테스트·예측 성능 검증이 아닙니다.

실측은 `data/live`의 읽기 전용 원장 재현입니다. 새 공식 XLSX 다운로드/재파싱 또는 독립 원천 교차검증이 아닙니다. 원장의 실제 기존 정정 기록과 인위적인 정정 시험을 구분합니다. 2026-10 이후는 TOURGO 승인 범위 밖으로, 새 월 진단을 준비 완료로 표시하지 않습니다.

## 비공개 발행물과 보존 계약

`briefing()`은 목표월의 두 핵심이 적격할 때만 초안을 생성합니다. 실제 산출물은 저장소 밖에만 보관합니다.

| 파일 | 내용 |
| --- | --- |
| `inputs/config.json`, `archive.json`, `policy.json` | 실제 입력 전체 사본·승인 근거 |
| `diagnostic-private.json` | 원지표, 비교월 원관측, 기록된 원본 해시/빈티지, 경고, 방법론 |
| `briefing-private.json` / `.md` | 근거 2개, 기준월/비교월/출처, 한계, 편집 검토 대기 |
| `retrospective-private.json` | 69개월 현재 빈티지 회고·독립 산식 검산 |
| `sensitivity-private.json` | 반사실 시나리오·검증 결과 |
| `manifest.json` | 파일별 SHA-256, 입력 해시, 구현/계약 파일 해시, 방법론/도구 버전, 월간 shadow_id, 검토본 revision, 이전 manifest 해시 연결 |

전체 시장 판정은 산업 활동 부재로 항상 `withheld`, 게시 승인은 항상 false입니다. 국적·출국·지급은 보조 영역이며 초안 근거에 합산하지 않습니다. 근거는 두 핵심의 사실 문장 2개이고 상한 3개를 넘기지 않습니다. 모집단이 다른 방한객과 국제수지 일반여행수입을 나누어 1인당 소비를 만들지 않습니다.

새 디렉터리만 생성하고 덮어쓰기를 거부합니다. 디렉터리 0700/파일 0600을 사용합니다. `--previous`는 이전 파일 해시를 검증하고, 같은 기준월의 이전 manifest 해시·입력 해시·변경 여부를 연결합니다. 이전 검토본 내부로 쓰는 것도 거절합니다. 검토본이 늘어도 같은 `shadow_id`인 월간 초안 1건의 이력이며 홈페이지 발행 건수가 아닙니다. 단순 재실행을 공식 통계 정정이라고 부르지 않습니다.

`verify_bundle()`은 파일 누락·추가·변조를 검출합니다. 자체 manifest 해시는 전자서명이나 외부 공증이 아니므로 원자료의 진위·권리 승인까지 입증하지 않습니다. 이전본과 manifest의 보안 보관은 필요합니다. 편집 검토 결과를 기록하려면 새 검토 이력을 보존하는 별도 절차가 필요하며 현재 도구는 자동 승인하지 않습니다. `pending`, 검토자/검토시각 null을 유지합니다.

```sh
python -m src.macro.weather_shadow \
  --snapshot /absolute/private/read-only-data-live-copy \
  --output /absolute/private/new-shadow-directory \
  --target 2026-09 --start 2021-01 --end 2026-09
# 이후 별도 검토본: 새 --output 및 --previous /absolute/private/previous-directory
```

저장소·운영 입력 사본 안에는 출력하지 않습니다. 기본 기준월은 이번 검증 대상이며 새 승인 범위로 자동 확대하지 않습니다. 실제 초안과 반사실 자료를 공개 Git·사이트·아티팩트 경로로 이동하지 마십시오. Actions 실행 도구나 워크플로는 추가하지 않습니다.

## 향후 홈페이지 정보 구조와 현재 가능 범위

아래는 문서상의 제안이며 `site/` 또는 시뮬레이터를 구현·변경하지 않습니다.

| 화면 영역 | 현재 비공개 초안에서 가능한 내용 | 아직 구현/승인되지 않은 내용 |
| --- | --- | --- |
| 제목·상태 | 기준월, 방한·일반여행수입 부분 모니터, 종합 판정 보류 | 관광시장 전체 상태·점수·날씨 등급 |
| 두 흐름 | 정확한 원값·단위, YoY, 비계절조정 MoM, 비교월 | 실질 소비·관광 카드소비·산업 활동 해석 |
| 주요 근거 | 최대 3개 중 실제 2개 사실 문장, 출처 | 인과·호황/위기/회복 자동 문구 |
| 주의사항 | 기준월·입력 마감·시차·결측·팬데믹 기저·정정 | 역사적 as-of 인증, 계절조정 모형 |
| 이전 발행·정정 | 비공개 사본/해시 연결·검토 대기 | 공개 아카이브·공개 정정 고지 UI·게시 승인 |
| 보조 설명 | 원장에 있는 국적·출국·지급을 별도 참조 가능 | 신규 ECOS/항공 등 미승인 입력의 사용 |

향후 월간 편집은 두 핵심의 동일 기준월 확보·승인 확인 후 사람이 검토하는 방식이 후보입니다. 달력상 특정 날짜에 데이터가 없는데도 자동 발행하지 않습니다. 이번에는 운영 일정·자동 발행·공개 콘텐츠를 만들지 않았습니다.

## 남은 검토

실제 발표일/원본 빈티지와 독립 교차검증, 팬데믹 회복기의 해석, 시차에 따른 편집 기준, 권한을 갖춘 편집자의 검토 기록, 별도 홈페이지 게시 승인이 필요합니다. 산업 활동 입력이 없는 동안 전체 시장 진단을 만들지 않습니다. 정정 시험은 합성 검증이며 실제 제공기관의 소급 정정을 확인한 것과 구분합니다. 이번 검증은 콘텐츠 생성 가능성과 계산·보존 안정성을 확인하며 시장 진단의 예측력·경제적 타당성을 입증하지 않습니다.

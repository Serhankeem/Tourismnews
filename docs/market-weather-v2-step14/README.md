# Step 14 — 월간 진단 UI v0.1 / 로컬 Preview

PR #55 병합 후 main `44a95770a119b6de0dd301506c73c91357146da4` 기준입니다. Issue #49의 Step 11B~13과 `weather_diagnostic.py` / `weather_shadow.py` 출력 계약을 사용합니다. **운영 홈페이지 통합·정규 발행·배포가 아닙니다.**

## UI 구성

`preview/market-weather/`의 HTML/CSS/ES module은 `site/` 밖에 있습니다. 기존 딥블루 `#173B73`, 화이트·그레이, 시스템 글꼴을 사용한 월간 편집형 레이아웃입니다. 외부 글꼴·차트 라이브러리·이미지 요청이 없습니다.

- 월간 헤더: 발행월은 **미정·미발행**, 통계 기준월·자료 마감(KST)·현재 빈티지 분석을 별도 표시합니다.
- 산업 활동 부족에 따른 **종합 판정 보류**, 두 핵심의 부분 모니터임을 표시합니다.
- 방한객과 명목 US$ 국제수지 일반여행수입의 원값·단위·기준월, 비교월이 명시된 MoM/YoY.
- 승인된 최근 12개월의 반응형 SVG 추이, 정확한 월별 수치 표를 키보드로 펼칠 수 있습니다. 구간 최소·최대 축(0 기준 아님)을 명시하며 결측 월은 연결하지 않습니다.
- 실제 근거 2개(상한 3개), 공식 원문 링크. 누락된 지표의 근거는 제외합니다.
- 정의·모집단·계절성·시차·기저효과·정정·현재 빈티지 한계.
- 과거 발행물·방법론·정정/검토본 이력의 정보 구조. 실제 공개 아카이브를 만들거나 비공개 검토본을 발행 이력으로 표시하지 않습니다.

숫자가 없으면 `자료 없음`, 비교율이 없으면 `비교 불가`를 표시합니다. 임의 예시값·0 대체·전월 보충이 없습니다. 변화율 표시 반올림은 BigInt 기반 2자리 HALF_UP이며, 계산 원본은 엔진의 Decimal 문자열입니다. 수치 증가/감소를 호황/침체로 해석하지 않습니다.

## 격리 경계

1. `tools.market_weather_preview`만 `127.0.0.1`에 바인딩합니다. 외부 호스트 지정 옵션·프록시·터널·Preview 배포를 추가하지 않습니다.
2. 기본 실행은 데이터 없는 레이아웃입니다. `--bundle`을 명시하면 Git 밖 Step 13 묶음의 manifest/파일 해시를 검증하고 현재 main 설정·정책의 수집/게시 승인 범위를 다시 검사합니다.
3. API는 두 핵심과 필요한 근거·검토 정보·12개월 원값만 투영합니다. 원장 파일·정책·manifest를 정적 제공하지 않습니다. 신규 ECOS·항공 입력은 없습니다.
4. 같은 로컬 서버에서 받은 HttpOnly / SameSite=Strict 세션 쿠키가 있어야 API를 읽을 수 있습니다. Host·Origin·Sec-Fetch-Site 검사, no-CORS, no-store, noindex, no-referrer, 프레임 차단 CSP를 적용합니다. 외부 URL·API 키·스토리지·다운로드 기능이 없습니다.
5. `renderReport()`의 기본 공개 모드는 수치·근거를 렌더링하지 않습니다. 승인 플래그 하나를 true로 바꿔도 공개 통합은 잠겨 있습니다. 비공개 렌더링 인자는 서버 격리의 대체 인증 수단이 아니며 공개 사이트에 포함시키면 안 됩니다.
6. 루프백 서버는 같은 머신의 사용자가 접근할 수 있으며 원격 로그인 서비스가 아닙니다. 실제 데이터가 있는 상태로 공유 호스팅·공개 URL·터널을 만들지 마십시오. 별도의 인증/권한·게시 승인 설계 없이는 배포할 수 없습니다.

기존 Pages 조립은 `site/`와 승인된 공개 파일 목록만 복사합니다. 실제 `compose()`를 격리 실행해 Preview/비공개 JSON 미포함, 새 관측치 미포함, main 기준 조립물과 전체 파일 바이트 일치를 확인했습니다. 미연동 지표의 기존 빈 메타데이터는 유지하며 활성 지표는 기존 KTO/TOURGO 9개·621개 관측입니다.

## 안전한 실행

저장소 루트에서 데이터 없는 Preview를 먼저 실행합니다.

```sh
python -m tools.market_weather_preview --port 8044
```

현재 환경에서 검증한 비공개 묶음은 다음과 같이 선택할 수 있습니다. 원본을 복사하거나 수정하지 않습니다.

```sh
python -m tools.market_weather_preview \
  --bundle /workspace/work/weather49-step13-shadow-2026-09-review \
  --port 8044
```

같은 머신의 브라우저에서 `http://127.0.0.1:8044/`를 엽니다. 위 경로는 격리 환경의 파일이며 저장소에 포함되지 않습니다. 원본이 없는 환경에서는 기본 무자료 Preview만 사용할 수 있고 실측 검수에 성공했다고 표시하지 않습니다. 잘못된 묶음·현재 승인 범위 초과는 서버 시작 실패로 차단합니다. 로그에는 고정 오류 코드만 남깁니다.

## 검증 및 재현

```sh
python -m unittest discover -s tests -p test_market_weather_preview.py -v
MONTHLY_PREVIEW_SCREENSHOTS=/absolute/private/screenshots \
  node tests/market-weather-monthly.smoke.cjs
# axe-core를 테스트 환경에 별도 설치한 경우:
# MONTHLY_AXE_SOURCE=/absolute/test-only/axe.min.js 추가
```

브라우저는 Playwright Chromium을 사용합니다. 개발 환경의 별도 브라우저/axe 설치는 Git에 넣지 않습니다. 테스트용 axe 스크립트는 브라우저 요청 인터셉트로만 주입하며 서버·공개 자산에 추가하지 않습니다. axe는 WCAG 2 A/AA·2.1 AA 태그의 자동 검사이며 전체 접근성 인증이나 실제 스크린리더 검수를 대신하지 않습니다.

실측 검수 범위는 Step 13의 2026-09 승인된 두 핵심입니다. 네 가지 폭(320/390/768/1440), 키보드 skip/disclosure, 수치·원문 링크·SVG 표, 결측·지연·접근 실패·무자료·공개 승인 없음·플래그만 변경한 공개 차단을 확인합니다. 스크린샷은 **실측 자료가 있으므로 Git 밖에만 보존**합니다.

공개 회귀는 현재 운영 데이터를 사용하는 `market-weather-public-preservation.smoke.cjs`, 기존 `home.smoke.cjs`, `briefing-observation.smoke.cjs`, `header-weather-v22.smoke.cjs`로 확인합니다. 구형 `macro.smoke.cjs`와 `market-weather-v2.smoke.cjs`는 각각 TOURGO 연결 전 핵심 2개, 금액 지표도 인원 관측 카드에 표시된다는 가정으로 현재 운영 데이터에서 실패했습니다. 이 테스트를 변경하거나 실패를 통과로 표시하지 않았습니다. main 조립물과 바이트 동일성이 확인됐으며, 현재 승인된 4개 Macro 핵심 카드·9개 연결 계열·621개 관측과 금액/인원 분리·시뮬레이터/실패 보존은 새 회귀로 검증했습니다.

권한 있는 편집자의 검토, 실제 게시 승인 및 공개용 스키마/발행본 투영, 서버 측 공개 차단·정정 아카이브, 별도 UI 통합·접근성 수동 검수·배포 승인이 필요합니다. 현재 로컬 UI는 그 작업을 승인하거나 자동 수행하지 않습니다. 기존 시뮬레이터·Macro·Daily Briefing·뉴스·리서치·승인 설정·운영 원장은 변경하지 않습니다. 점수·가중치·날씨 등급을 새로 만들지 않습니다.

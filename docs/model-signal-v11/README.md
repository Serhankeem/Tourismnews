## 구현 계약

`src/model_signal/v11.cjs.evaluateSnapshot(raw, {expected_sha256, as_of_period, reference_period?})`:

1. 외부 원본 바이트와 명시적 SHA-256 일치를 먼저 확인한다. 해시는 무결성 핀이며 승인 증명이나 Secret이 아니다.
2. 기존 검증 모드·두 계열 ID·enabled/connected·원장 월 집합과 현재 승인범위를 확인한다. TOURGO 2026-10 이후의 현재 가시 관측은 거부한다.
3. 미래 관측은 계산에서 제외한다. 자동 선택은 양쪽의 마지막 명시적 공통월, 회고 검증은 요청월과 정확히 일치해야 한다.
4. 최신월이 앞선 계열의 실제 최신 관측·중복 latest·YoY·공식 파일 증거도 검사한다. 공통월이 더 과거라고 최신 무결성 오류를 숨기지 않는다.
5. 선택된 월에서 기존 `site/market-signal-model.js.evaluate`를 호출한다. **39개월 연속, 정의·단위·출처·권리, 분모, 3개월 시차**와 BigInt 유리수·반올림·중간순위 산식을 재사용한다. 선택월의 창이 불완전하면 더 과거의 점수를 찾아 성공으로 바꾸지 않는다.
6. 정정 상태·존재하는 공표/수집시각의 형식·수집시각 선후를 검증한다. 미확인 값은 만들지 않는다. 정정된 입력은 새 해시로 분리해 결정적으로 재계산하고 원본을 변경하지 않는다.

시차는 달력 월 차이: 2026-09는 2026-12 분석까지 3개월로 허용, 2027-01에는 `stale_reference_period`로 유보한다. 한 계열이 없으면 다른 계열로 재가중하지 않는다. 결측·오류 시 `score=null`, `weather=null` 및 구체적 reason을 반환한다. 모든 출력은 `publication_approved=false`, `retrospective_current_vintage`, `historical_as_of_verified=false`다. 과거 기준월의 해시는 당시 빈티지의 증거가 아니다.

## 7개 방식 재현 비교

새 공식 데이터 탐색 없이 같은 실제 두 계열을 사용했다. 변환·정규화·참조창·가중치·교란 조건은 계산 전에 격리 출력의 protocol.json으로 고정했다. 사용자 제공 기준점은 이미 알고 있었으므로 맹검 또는 미지의 최적화 실험이라고 주장하지 않는다. 비교 가능한 전체 기간과 **공통 19개월(2025-03~2026-09)**을 분리했다.

| 방법 | 9월 점수 | 계산 가능 기간(개월) | 공통월 점수 절대변화 평균 | 공통월 표시구간 전환(18회 비교) |
|---|---:|---|---:|---:|
| 3개월 평활 YoY·24개월 백분위 **채택** | 62.50 | 2024-03~2026-09 (31) | 11.46 | 9 |
| 3개월 평활 YoY·36개월 백분위 | 56.94 | 2025-03~2026-09 (19) | 9.65 | 4 |
| 평활 없는 YoY·24개월 백분위 | 37.50 | 2024-01~2026-09 (33) | 19.10 | 12 |
| 12개월 누적 YoY·24개월 백분위 | 75.00 | 2024-12~2026-09 (22) | 7.18 | 5 |
| 평활 YoY·Z-score | 57.34 | 2024-03~2026-09 (31) | 9.57 | 5 |

| 평활 YoY·Min-Max | 49.68 | 2024-03~2026-09 (31) | 10.61 | 7 |

백분위 네 방식은 Fraction으로 정확히 계산한다. Z는 직전 24개 표본의 **모집단 표준편차**, MAD는 중앙값과 `1.4826×MAD`로 정규화 후 정규 CDF를 적용한다. Min-Max는 직전 창 최솟값/최댓값으로 0~100에 제한한다. 정규화 방식의 CDF는 수치 계산용 링크 함수이지 관광 성장 확률이 아니다. 전부 타깃월을 참조분포에 넣지 않는다.

**선정·기각 근거:** 채택 모델은 설명 가능성·기존판본 비교·39개월 기술 최소조건을 유지한다. 36개월 창은 이 표본에서 전환이 적지만 필요 이력이 51개월이고 평가월이 줄어든다. 무평활은 단기 변화가 커지고, 12개월 누적은 반응이 더 느리다. Z/MAD/Min-Max는 분포·스케일·극단값에 대한 별도 가정을 추가한다. 낮은 변동성이 곧 더 정확한 모델이라는 근거는 없다. 원래의 24개월 경험적 백분위를 유지하고 **공표 시차 처리만 바꾼다**.

각 방식의 실제 필요 원값 창 전체에서 하나의 값만 ±0.5%/±2% 바꾸는 **44,384건**의 가상 교란을 수행했다. 공식 관측을 정정한 것이 아니며 분수 복사본만 사용했다. 채택안은 각 방향 1,482건: ±0.5% 표시구간 변경 0건, -2%/+2% 각 2건, 최대 점수 차이 4.1667이다. 40:60/60:40은 공통월 38건 중 8건 구간 변경, 최대 7.9167점 차이다. 이를 근거로 50:50을 바꾸지 않았다. 다른 방식의 상세 집계는 [comparison.json](comparison.json)에 있다.

타깃 이후 관측을 제거한 prefix와 전체 원장에서의 동일 월 계산 **396건**이 일치했다. 채택안의 31개월은 별도 Python Fraction과 기존 JS BigInt 계산이 일치했다. 2022-12 이하 원값을 모두 배제하면 24개월 방식 7개월만 남고, 36개월 방식은 0개월이다. 팬데믹 기저효과·구조 변화에서 벗어난 장기 안정성을 입증할 표본이 부족하다. 독립 관광경기 정답자료가 없으므로 **예측 정확도 순위·최적 경제 가중치·산업 전체 설명력은 입증하지 않았다**.

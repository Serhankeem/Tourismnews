## 기존 자산의 근거 수준

- [Step4](../market-weather-v2-step4/README.md), [Step6](../market-weather-v2-step6/README.md), [Step9](../market-weather-v2-step9/README.md)는 기존 검증 기록이다. 이번 원본 재열람 결과는 [심층 보고서](priority-five.md)에서 별도로 구분한다.
- Step3 원본 63개 응답을 읽어 기존 manifest/메타 해시와 대조하고 집계 데이터·628개 월별 fingerprint가 현재 fixture와 같은지 확인했다. fixture의 해시만 보는 것으로 원본 재파싱을 대체하지 않았다.
- Step5 ECOS 지침 캡처와 Step11A 별도 BOK PDF/대조 기록은 기존 manifest에 대해 해시를 재검증했다. 현재 ECOS SPA 본문이 읽히지 않은 점을 숨기지 않으며, 그렇다고 과거 확인한 BOK 작성 통계 이용허락을 다시 막연한 미확인으로 바꾸지도 않는다.
- 항공 manifest에 든 XLSX4개는 실제 재파싱했다. 보조 인천 XLS2개는 해시만 재검증했으며 현재 BIFF 값 재파싱은 하지 않았다. 정의·일정·매뉴얼 PDF3개의 원본 해시도 확인했다.
- Step3에서 보관한 원작성기관 PDF의 웹 추출/검색 캡처는 그 원본 PDF 파일 자체가 아니다. 여가 지수의 과거 9개월 부분 대조를 이번 독립 재검증으로 세지 않는다.
- 현재 data/live 공개 Macro blob을 SHA로 검증했다. 이는 공개 projection이며 공식 XLSX 독립 재파싱의 대체가 아니다.

원본·응답·기존 약관 캡처·가공 결과·로컬 검증 스크립트는 저장소 밖 `/workspace/work/model-source-audit-20261123/`에 보존한다. PR에는 원값, 관측치 해시 목록, 원고/승인기록 또는 비공개 응답을 포함하지 않는다.

전국 15개 공항은 김포·김해·제주·청주·대구·무안·양양·광주·울산·여수·포항경주·사천·군산·원주·**인천**이다. 국제선 **출발+도착**, 정기+부정기, **여객기+화물기**를 포함한다. 선택 공항 전체의 시계열 합계에 인천을 다시 더하지 않는다. 별도 공항별 원본은 2025-09·2026-09의 합계 확인에만 쓰며 추가 관측으로 세지 않는다.

**권리/시점:** [KAC 일반 안내](https://www.airport.co.kr/www/cms/frCon/index.do?MENU_ID=1260)와 [인천 저작권 정책](https://www.airport.kr/ap_ko/1033/subview.do)은 공동 수치 파일의 반복 수집·단체 내부 장기 보관·가공/재배포 허락을 확정해 주지 않는다. 특히 인천 정책의 기관 내부 복제 제한을 무시하지 않는다. 국토부 15092537의 별도 이용허락을 이 파일에 전용하지 않는다. **권리 pending 상태에서 추가 상관/모형 분석은 진행하지 않았다.** 월간 통계이지만 각 파일 실제 공표일은 null/미확인, finality는 not_stated다. 다운로드일로 공표일을 만들지 않는다.

## E. C14 숙박서비스 CPI

**식별:** ECOS `901Y009 / K02`, M, **2020=100**, 숙박서비스 가격지수. 기존 70개월의 원본/메타데이터와 fingerprint를 재확인했다. 현재 [KOSIS 원표 접근 후보](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1J22003)는 실패했으며 정확한 K02 매핑/70개 수준값 독립 대조는 미완료다. 호텔 MoM 등 다른 하위 품목의 과거 비교율을 K02 전체의 수준 대조로 대신하지 않는다.

**기준년:** [국가데이터처 공식 공지](https://mods.go.kr/board.es?act=view&bid=213&list_no=445795&mid=b70203010000)를 현재 재열람했다. 2025 기준 개편 결과는 **2026-12-18**, 새 기준의 12월·연간 동향은 **12-31 예정**이다. 2025-01~2026-11 기존 수치도 바뀔 수 있으며 품목 분류·대표품목·가중치 변경이 예정돼 있다. 2026-11-23 현재 실제 개편 결과/새 K02 매핑/연결 계수는 미확인이다.

2020 계열을 보존하고 새 기준은 별도 계약 revision·원본 빈티지로 관리한다. 원작성기관 연결표와 겹치는 기간의 비교 검토 전 자동 연결·대체를 하지 않는다. 제공기관 코드가 같아도 단위/기준년 변경이면 기존 계열을 갱신하지 않아야 한다.

**권리/역할:** ECOS 비상업 연구 이용 근거는 있으나 원작성기관 데이터·가공 공개 조건을 별도로 확인한다. 개편 공지의 공공누리1은 해당 공지의 조건이며 통계 DB 전체의 라이선스로 확대하지 않는다. CPI는 가격·비용 환경 변수다. 수요량, 실판매 ADR·객실 매출이 아니며 호텔/여관/콘도와 상위 숙박서비스를 각각 독립 신호로 중복 가중하지 않는다.

## Phase2-B에서 확인할 공통 통계 위험

- 2021~2026의 코로나 이후 회복·정의/행태 변화는 단순 추세 상관과 성장률을 왜곡할 수 있다. 회복기 포함/제외 구간을 결과 관찰 전에 정하고, 비계절조정 자료와 조정 자료를 구분한다.
- 공표 시차가 다른 최신월을 강제로 맞추거나 앞으로 나온 자료를 과거 평가월에 넣지 않는다. 현재 보유 전5개와 기존 핵심2개의 공동 목표월은 2026-09를 검토할 수 있지만 2026-10 핵심 입력이 확보됐다고 간주하지 않는다.
- 각 축의 원값·YoY·평활 변환을 별도 비교하고 겹치는 3개월 평활/24개월 참조를 독립 표본24개로 세지 않는다. 계열 추가 전 기준 모델 대비 중복·정정·결측·구조 변화 민감도를 사전 계획한다.
- 공표일/finality가 미확인인 기존 관측은 null/not_stated를 유지한다. 과거 당시 원자료 빈티지가 없으면 `retrospective_current_vintage`이며 실시간 백테스트·예측 성능을 주장하지 않는다.
- 이 문서의 품질 카운트는 기술 적격성의 일부다. 통계적 설명력 개선·다변수 모델 점수·가중치 변경을 검증한 문서가 아니다.

## 2. Codex가 추가 검증할 수 있는 작업

권한 확대 없이 가능한 과업은 공식 공표표·설명서·코드북 검색과 공개 화면 확인, 이미 있는 원본의 해시/기준월/정의 검증, 통계표의 현재 단위·기준년·공표 일정 비교, **조건이 확인된** 파일의 격리 분석이다. KOSIS 접근 실패는 허용된 기관 공표표·첨부 파일로 대체 조사할 수 있다. 제한을 우회하거나 동일 ECOS의 다른 화면을 독립 원표로 세지 않는다.

C18은 먼저 전국 숙박·음식점업 BSI 세부 원표의 존재와 범위를 확인한다. 광의 비제조업 CBSI만 확인되면 목표 BSI 후보를 확보한 것으로 표시하지 않는다. C03도 실제 숙박일수/박수 항목을 확인한 후 정의 적합성을 판단한다.

모든 새 자료에는 파일 SHA-256·공식 다운로드 URL·조회일·실제 공표일(미확인이면 null)·집계 조건·빈티지·잠정/확정 상태를 보존한다. 원본과 변환 결과를 분리하고 수정 관측은 기존 빈티지를 덮어쓰지 않는다. 이번 PR은 이 수집을 구현하거나 실행하지 않는다.

## 4. Phase2-B 권장 순서 — 우선 5개

1. **C10 숙박업 생산**: 관광산업 활동에 가까운 후보이며 69개월 원본이 있다. 같은 업종의 원작성 원표 확보·독립 수준값 대조를 먼저 해결한다. 소수점/기준년 보존과 비계절조정·공표 시차 검증을 병행한다.
2. **C13 월평균 환율**: BOK 이용허락 근거와 70개월 원본·별도 공표2개월이 있다. 이미 성공한70개월 인증의 Summary 보존·키 범위 점검과 평균 정의/산식 및 추가 별도 공표자료 확인. 재실행은 필요 사유와 별도 승인 시에만 수행. 수요와 같은 방향의 핵심 가중 입력으로 승격하지 않는다.
3. **C11 여가 생산**: 69개월 원본을 재활용해 원작성 대조를 확대한다. 관광 외 비중은 분해 자료 없으면 수치화하지 않는다. 숙박/기존 핵심과의 중복 분석은 내부 연구 조건·원표 대조 범위를 명시한 후 수행한다.
4. **C14 숙박 CPI**: 70개월 원본의 K02 수준값 대조와 2025 기준 개편의 코드/분류/소급 범위를 확인한다. 구기준 보존과 새기준 별도 판본을 전제로 하며 단기 수요 점수 입력 대신 가격 해설을 우선한다.
5. **C07 국제선 운항**: O1 이용범위 확인 후 70개월 정의/독립 대조·정정/공표 정보 확장. 공급좌석 대체 없이 접근성 대리로 검토한다. O1 미해결이면 이 순서의 실제 분석은 보류한다.

이 순서는 새 변수의 모형 채택·가중치 결정 순서가 아니다. C01 출국은 기존 보조 관측으로 원본 검토를 병행할 수 있으나 신규 관광산업 활동 축 확보보다 우선하지 않는다.

## 5. Phase2-B 진입/종료 기준

- 시작 전 각 대상의 수집 허용·내부 연구·공개 이용조건을 분리하고, 인증이 필요한 요청의 계열·기간·실행 횟수를 사용자가 별도 승인한다. 이번 사전 연구 승인을 Actions 실행 승인으로 해석하지 않는다.
- 공식 원표를 실제 열어 같은 정의·월·단위·기준년으로 비교한 구간과 미대조 구간을 모두 기록한다. 파일 없이 설명/검색/기존 연구 기록만 있으면 완료 처리하지 않는다.
- 신규 또는 가공 시계열은 저장소 밖에 둔다. 통계적 분석을 수행한다면 지표 변환·기저효과 구간·결측·공표 지연·빈티지/누출 방지·중복 평가 기준을 분석 전에 고정하고 독립 검증 범위를 명시한다.
- 설명력 개선·인과·예측 정확도나 가중치/날씨 구간을 확정하지 않는다. 새로운 모델 판본/운영 투입/게시 승인은 이후 별도 심사다. 현재 v1.0과 62.50점은 유지한다.

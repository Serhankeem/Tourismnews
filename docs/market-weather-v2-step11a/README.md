## 2. 별도 장기 인증 검증 도구 — 실행하지 않은 준비물

기존 `Market Weather ECOS Preflight`와 그 최신 3개월 로직은 **수정하지 않았습니다**. 새 `Market Weather FX History Preflight`는 기존 클라이언트·소수점 파서·등록 검증·pinned fingerprint·안전 Summary 파일 검증을 재사용합니다.

1. `workflow_dispatch` + `main`에서만 수동 실행. `contents: read`, 기존 Preflight와 같은 concurrency lock, 15분 제한. 키 없는 합성 테스트 후 마지막 단계에만 `secrets.ECOS_API_KEY` 주입.
2. 표·항목·단위·M주기·메타데이터 범위를 검증하고 **고정 2026-08~10 3개월**을 먼저 재조회합니다. 이 단계가 실패하거나 값이 다르면 67개월 요청을 하지 않습니다.
3. 게이트 통과 시 **고정 2021-01~2026-07 67개월**만 추가 조회합니다. 현재 시점이 바뀌어도 이 검증의 범위를 자동 연장하지 않습니다. 보통 메타데이터 2개 서비스 + 관측 2개 서비스이나 메타데이터 pagination/robots 요청이 추가될 수 있습니다.
4. 정확한 월 집합·중복·결측·코드·단위·정밀도와 기준 패키지 fingerprint를 대조합니다. 정정 후보는 월만 표시하고 **실패/검토 필요**로 종료합니다. 기준 패키지·원장 값을 바꾸지 않습니다.
5. 출력은 상태·인증 판정·단계·검증/일치/정정 후보/미조회 건수·후보 월만 허용합니다. **값·응답 원문/해시·키/키 URL·HTTP 헤더·원문 예외·아티팩트는 출력/업로드하지 않습니다.** 응답은 메모리에서만 처리합니다. 주입 모의 응답은 반드시 simulation_only/not_verified입니다.

새 파일: `src/macro/ecos_fx_history_preflight.py`, `.github/workflows/ecos-fx-history-preflight.yml`, `tests/test_ecos_fx_history_preflight.py`. 새 정기 컬렉터나 운영 파이프라인은 아닙니다.

**향후 실행 절차(지금 실행 금지):** Draft PR 리뷰 → **별도 병합 승인/사용자 병합** → main의 해당 커밋 확인 → **이 고정 70개월 읽기 전용 실행에 대한 별도 사용자 승인** → Actions → `Market Weather FX History Preflight` → Run workflow → main → 1회 실행. 기존 키는 GitHub Secret에 유지하고 Codex 환경에 복사하지 않습니다. [공식 API/FAQ](https://ecos.bok.or.kr/api/) 기준 키 유효기간은 발급 후 2년·연장 가능이며 실제 키 날짜를 인증 성공에서 추정하지 않습니다. 운영자는 MyPage에서 발급일·만료일·신청 목적·담당자를 확인해 **키 값 없는 관리대장**에 남기고 만료 60일 전 점검·30일 전 연장 요청을 권고합니다. 숫자로 보장된 요청 한도는 미확인이며 실제 서비스 제한 응답을 존중합니다.

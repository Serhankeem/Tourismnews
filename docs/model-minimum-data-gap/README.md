## 접근·권리와 남은 조치

**C10:** [현재 KOSIS 공식 공표표 목록](https://kosis.kr/serviceInfo/newContrainDataDetail.do?boardIdx=1999001&boardOrgId=101)이 이번에도 HTTP503이었다. 과거의 legacy 표 ID를 확정 코드로 사용하지 않았다. 기존 ECOS 원문/집계와 628개 baseline fingerprint를 오프라인 재확인했고, 보관된 KTO 재공표 PDF 해시도 기존 기록과 일치했다. 숙박업 수준값 차이 **2022-11·2023-10·2023-11 세 건**은 그대로 남는다. ECOS/KOSIS의 기존 출처표시 기반 비상업 연구 이용근거를 철회한 것이 아니라, 원표·빈티지 대조 미해결 때문에 투입을 보류한 것이다.

**C12:** 공식 시작 URL은 `https://eis.work24.go.kr/`, 메뉴는 **고용보험 → 피보험자 → 산업/규모별 피보험자현황(월)**이다. 확인 화면 경로는 `/eisps/rpt/reptDtl.do?menuId=050020040`. 제공기관 설명은 월말 기준 상용직 또는 자영업 피보험자, 복수 사업장일 때 최근 취득 사업장 기준 중복 제거, 단위 명이다. 여러 달의 재고 인원을 더하면 안 된다. 공개 뷰어의 기본 마감월 인자는 `202610`이었으나 이를 실제 관측치·최신월 확보로 보고하지 않았다.

일반 HTTP로 공개 화면과 연결된 뷰어 HTML은 받았지만, 브라우저는 **`net::ERR_CERT_AUTHORITY_INVALID`**로 실행하지 못했다. 공식 사이트가 로그인을 요구한다고 확인한 것은 아니다. TLS 검증을 해제하거나 뷰어의 내부 다운로드 요청을 추측하지 않았다. 현재 확인한 산업 대분류를 숙박업 단독으로 대체하지 않았고, 숙박업 선택코드·KSIC 버전·공표 시차·정정 이력은 미확인으로 남긴다.

공식 저작권 정책 경로 `/eisps/etc/selectCpyrPtcnPoly.do`에서 **출처를 구체적으로 표시하는 무료 자유 이용** 근거를 확인했다. 수익/혜택 목적 사용은 별도 협의·허락, 외부 게재의 내용 변경과 세부화면 링크에는 별도 제한이 있어 내부 연구와 홈페이지 재배포를 구분해야 한다. 원본이 없으므로 이번 연구 적격성 전체를 충족한 것은 아니다. 보고서에는 화면 경로를 메타데이터로 남기고 해당 사이트를 임베드하지 않았다.

**C02:** 해당 첨부의 공식 게시물은 **공공누리1(출처표시)**를 표시한다. 출처·원작성/재공표기관·자료 빈티지·원래 단위를 유지한 내부 보관과 비공개 가공 연구의 근거로 사용했다. PDF 전체나 가공 시계열을 공개 PR에 올리지 않았고 새로운 홈페이지 게시 승인을 부여하지 않았다. 출처 표기안: `문화체육관광부·한국문화관광연구원, 2026년 국민여행조사 2분기 결과(잠정치), 한국관광공사 관광데이터랩 재공표, 조사 기준월, 조회일. 월별 자료 정리는 여행기류.`

**C05:** [공식 지역별 관광소비 화면](https://datalab.visitkorea.or.kr/datalab/portal/loc/getAreaDataForm.do)의 다운로드 제어를 확인했다. 실제 로그인 후 조회/다운로드는 하지 않았다. 현재 로그인 뒤 추가로 필요한 동의·사유/설문은 운영자가 실제 화면에서 확인해야 한다. 일반 이용약관·게시물의 공공누리 표시를 카드사 자료의 가공/재배포 허락으로 전용하지 않는다. 공식 전국 합계, 카드 제공사와 기간별 변경, 관광 업종, 확대계수, 온라인/간편결제 포함 여부는 원본/설명서가 없어 미확인이다. 지역화폐의 별도 안내를 카드소비 전체의 정의로 가져오지 않았다.

사용자에게 필요한 조치는 다음 **세 가지**다. 비밀번호·쿠키·키를 전달할 필요는 없다.

2. 최신 국내관광 입력이 필요하면 데이터랩에 정상 로그인하여 **공식 전국 합계·내국인 외지인·월간 관광 카드소비** 원본과 제공사/업종/추정계수/기간 변경 설명 및 내부 연구·보관·공개 조건을 함께 받는다. 전국 총액이 없으면 시군구 합산하지 말고 제공기관에 공식 집계를 확인한다. 먼저 동일 조건의 최근 월 원본과 메타데이터를 확인한 뒤 같은 정의의 장기를 확보한다.
3. C02만으로 과거 연구를 할 경우 **2023-01~2026-06, 천 회 원정밀도, 2026 잠정 및 집계 차이 고지**라는 범위를 결정한다. 2026-09 최신 연구에는 그 달이 실제 포함된 공식 공표본과 공개시점 검증이 따로 필요하다. C02의 과거 자료 확보를 C05 권리 확인이나 최신성 충족으로 대신하지 않는다.

## 국내관광 경로는 하나로 종료

선정한 서비스는 `https://apis.data.go.kr/B551011/DataLabService`의 **광역 지자체 지역방문자수 집계 기능**이다. 공식 문서는 `serviceKey`, `MobileOS`, `MobileApp`, 날짜 범위를 필수로 표시한다. 현재 실행 환경에 승인된 서비스키가 없고 서비스 활용신청 상태도 확인하지 못했으므로 인증 요청을 시도하지 않았다. 빈 키/샘플 키/비공개 경로로 대체하지 않았다.

포털은 무료·이용허락범위 제한 없음, 갱신 주기 “실시간”으로 표시하지만 실제 가용 관측기간·최신 일자·갱신 지연은 응답을 받지 않아 미검증이다. 제공 설명은 KT 내국인·SKT 외국인 이동통신 기반 **일자별 지역 순방문자**다. 한 사람이 여러 날 방문하면 여러 번 집계되고 광역/기초 기준도 달라 합산할 수 없다. 전국 고유 관광객·국내 여행 횟수로 변환하거나 지역/일자 합을 임의의 전국 관광객 수로 만들지 않는다. 이 서비스의 정상 활용신청·키 사용 범위가 확인될 때만 해당 지역 활동지표로 재개한다. 국내 점수는 생성하지 않았다.

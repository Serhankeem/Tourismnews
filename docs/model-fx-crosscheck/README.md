## 3. 별도 공식 자료 확보·대조 방법

[한국은행 공식 보도자료 검색 화면](https://www.bok.or.kr/portal/singl/newsData/list.do?menuNo=201150)의 제목 검색 `수출입물가지수` 및 화면에 제공된 100개 표시 옵션을 사용했다. 화면 JavaScript가 명시한 공개 HTML 목록 요청을 사용했으며, 비공개 API를 추측하거나 인증을 우회하지 않았다. 검색 결과의 공식 게시물에서 실제 PDF 첨부 링크를 따라 내려받았다.

선정은 2021-02~2026-10의 짝수 월 공표문 35개, 정밀도·차이 재확인을 위한 2022-03·2022-05·2024-03 공표문 3개다. 각 PDF의 실제 바이트·SHA-256·공식 URL·자료 공표일·조회시각을 보존했다. 원본과 원값 대조표는 비공개 격리 경로에 두고, [verification.json](verification.json)에는 출처·해시·검증 집계만 기록했다.

PDF에서 `원/달러 평균환율` 또는 `원/달러 환율(월평균)`이라고 표시한 부분만 사용했다. 기준 연월·직전 월·PDF 페이지를 확인하고 쉼표를 제거한 **Decimal 정확한 동등 비교**를 했다. 임의 오차 허용 범위는 적용하지 않았다. 첫째 자리 표에는 별도로 `ROUND_HALF_UP / 0.1원`의 명시적 표시 정밀도 검사를 적용했으며 원자료의 산식이 이 반올림 방식이라고 확정하지 않았다.

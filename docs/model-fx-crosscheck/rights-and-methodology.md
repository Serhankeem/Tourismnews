권리 근거는 [ECOS 통계정보이용지침](https://ecos.bok.or.kr/#/CustomerSupport/Notice/0000003136), **2026-06-17 시행**, Step 5 보관본이다. 한국은행 작성 통계는 출처를 명시하면 상업적 용도를 포함해 무료로 사용·가공·재배포할 수 있다는 조항을 재확인했다. 보관 HTML 및 본문은 Step 5 manifest 해시와 일치한다. 이번에 SPA의 최신 약관 본문을 새로 확보했다는 주장은 하지 않는다. 타 기관 작성 통계·다른 환율 제공업체의 서비스·PDF 전면 복제에는 이 조항을 무조건 확장하지 않는다.

향후 표시 예: `출처: 한국은행 ECOS, 주요국 통화의 대원화환율(731Y004), 원/미국달러 매매기준율 평균자료, 기준월 YYYY-MM, 조회일 YYYY-MM-DD. 변화율·분석은 여행기류 자체 계산.` 실제 공개에는 조회일을 해당 원본 빈티지와 맞춰야 한다.

## 2. 평균 산식과 제도 변화

[한국은행 외환 FAQ](https://www.bok.or.kr/portal/bbs/P0001949/list.do?menuNo=200658&searchOptn2=3)는 매매기준율을 외국환중개회사를 통한 최근 거래일의 원/달러 현물거래와 거래량 가중평균 개념으로 설명한다. 이는 **일별 기준율의 정의**다. 이를 월별 거래량 가중평균 산식이라고 바꿔 쓰지 않는다.

이번에 확보한 보도자료는 월평균임을 확인시켜 주지만, 월평균을 만드는 일별 관측일 집합·공휴일·결측일·가중 방식·중간 반올림·최종 반올림에 관한 완전한 계산 규칙은 제공하지 않는다. 민간 사이트의 “영업일 산술평균” 설명을 공식 산식의 확정 근거로 삼지 않았다. **공식 월평균 산식 확정과 일별 입력 재계산은 미완료**다. 일별 인증 API 호출을 추가하지 않았다.

향후 제도 변화 경보도 필요하다. [공식 입법예고 경로](https://opinion.lawmaking.go.kr/gcom/admpp/46878?announceType=TYPE6&mappingAdmRulSeq=2000000328168&ogLmPpList=%2Fgcom%2Fadmpp&ogLmPpUpdate=%2FopnPtcp%2Fadmpp%2F46816%2Fupdate&openYn=false&thisPage=detail)의 검색 색인에는 2027-01-01 예정 매매기준율 MAR→TWAP 개정안이 나타난다. 다만 이번에는 해당 공식 본문 파일을 직접 확보하지 못했다. **최종 시행 규정·ECOS 적용 계열·과거 재산출 여부는 미확인**이며 확정 변경으로 단정하지 않는다. 차기 데이터 확대 전 최종 공식 규정과 계열 메타데이터를 확인하고, 변경 시 정의 버전을 분리해야 한다.

## 3. 일반여행수입과의 향후 분석 권고

환율의 후보 역할은 **외부 거시환경·보조 설명 또는 통제 변수**다. 관광 수요의 직접 관측치로 두지 않는다.

1. 일반여행수입은 국제수지 개념의 **명목 US$** 흐름이다. 원화표시 국내 관광소비 총액이나 실질 소비가 아니다. 한국의 물가·원달러 환율만으로 단순히 실질 수입으로 바꿀 수 없다.
2. 원화 약세가 외국인의 원화 구매력에 미치는 효과와, 달러로 표시한 수입 환산·내국인 해외여행 비용·사업자 달러 비용에 미치는 효과는 다르다. 원달러 상승을 관광 성장의 양(+) 신호로 고정하지 않는다. 여행자의 자국 통화, 가격 책정 통화, 예약 시차·환헤지도 고려한다.
3. 수입과 환율의 수준 상관은 추세·코로나 회복기·가격·계절성 때문에 허위 관계를 만들 수 있다. 금액을 환율로 환산한 뒤 원계열과 높은 상관이 나오는 것은 계산상 관계일 수 있다. 같은 원천에서 파생한 신호를 독립 축으로 중복 가중하지 않는다.
4. 승인된 공통 기간에 한해 사전 고정한 월별 변화율/로그 변화와 지연 변수를 연구 후보로 둔다. 시차 후보·결측 처리·코로나 구간/기간별 민감도·다중 검정 제한을 결과 확인 전에 정한다. 70개월의 길이가 통계적 독립성이나 안정성을 보장하지 않는다.
5. 과거 평가에서는 해당 평가월 이후의 자료를 사용하지 않는다. 현재 빈티지를 사용한 계산은 `retrospective_current_vintage`로 표시하고, 역사적 공개 시점이 입증되지 않은 결과를 실시간 예측 성과로 보고하지 않는다.

이번 과업에서 상관계수·가중치·예측 정확도·새 점수·모델 개선 효과를 계산하거나 확정하지 않았다. Model Signal v1.0은 기존 두 계열과 50:50 구조를 유지한다.

## 5. Phase 2-B-3 진입 조건

자료 조사와 검증 방법 설계는 이어갈 수 있다. 환율을 포함한 본격적인 모델 기여도·상관 연구 전에 다음 조건을 확인한다.

- 입력은 해시로 고정한 검증 원본으로 한정하고, 2024-03 불일치와 2022-04 저정밀 검증을 명시한다. 원인을 해결하지 못하면 해당 월을 제외한 민감도 연구 등 제한적 범위를 운영자가 먼저 수용해야 한다. 임의로 값을 교체해 70개월 완전 검증 상태를 만들지 않는다.
- 동일 정의·통화·공통 기간을 고정한다. 일반여행수입은 기존 TOURGO 허용기간 `2021-01~2026-09`를 초과하지 않는다. 환율 2026-10 확보를 이유로 수입 기간을 늘리지 않는다.
- 통계적 관계의 분석 계획, 최신 빈티지의 회고적 한계, 계절성·기저효과·구조 변화·다중 검정 처리를 사전에 문서화한다.
- 외부 보조 지표로 검토하는 것과 활성 모델 입력으로 채택하는 것을 분리한다. 연구 결과만으로 가중치·운영 수집·홈페이지 게시를 자동 승인하지 않는다.
- 숙박업의 미해결 수준값 차이 3건은 별도 보류 상태로 남긴다. 환율 검증 진전으로 숙박업 또는 다른 미검증 계열을 통과 처리하지 않는다.

실제 독립 원천·산식 검증 완료 수는 여전히 0개월이다. 다만 별도 공식 공표자료 간 대조는 기존 두 달에서 69개월의 원정밀도 비교 및 1개월의 저정밀 확인으로 확대됐으며, 이를 추가 연구의 구체적 근거로 사용할 수 있다.
